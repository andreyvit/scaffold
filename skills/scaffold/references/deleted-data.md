# Deleted-data recovery

Keep ordinary user-deleted data recoverable for 30 days by default. Adjust where product requirements warrant a different window.

Use the [change/undo architecture](changes.md). Choose the storage representation and exposed recovery features for the project; no universal trash UI selected. This recovery window is separate from backup retention, analytics retention and explicit permanent-erasure policies.

User-data deletion and export are required capabilities; see [data export and deletion](data-rights.md).

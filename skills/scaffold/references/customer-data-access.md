# Customer data access and audit

Allow superstaff to access client data. Other users' access follows their permissions.

Keep an audit journal of meaningful customer-data access by any user:
- Record opening a customer details page.
- Do not record merely seeing a customer's name in a list.
- Record an export or other bulk operation as one bulk-operation entry, without enumerating every customer touched by default.

This policy does not grant all staff unrestricted access. Audit visibility, retention and event schema follow project requirements; no universal defaults selected yet.

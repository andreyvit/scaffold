# User data export and deletion

Provide user-data export and deletion as required capabilities.

Minimum viable export: a ZIP containing JSON files with all the user's data. Make the export available through an actual supported flow; choose its UI and schema for the product. Respect data ownership and access boundaries, including shared/company records.

Keep the [30-day ordinary deletion recovery default](deleted-data.md) distinct from explicit permanent-erasure handling. Reconcile deletion with retained history, audit and backups for the actual product requirements. No universal erasure deadline or import capability selected.
